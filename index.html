Build each answer, don’t memorize it

Every exam question gets a card. Each card takes two or three small steps. Each step asks you one quick thing, explains the answer, and opens the next step. By the last step you have the exam answer, and the reasoning to rebuild it.

The cards run in an order where each one uses the one before: waves, then pulses and power, spreading, gain, the target, the echo, the real world, and the hardware.

Tap an answer in each step. Wrong is fine: the explanation is the lesson.
